Three requests to get going

Copy each into a terminal. The first creates a container, the second puts a resource in it, the third reads the listing back.

1Create a container
curl -i -X POST {{STORAGE}} \
  -H 'Slug: notes' \
  -H 'Link: <https://www.w3.org/ns/lws#Container>; rel="type"'
2Add a data resource
curl -i -X POST {{STORAGE}}notes/ \
  -H 'Slug: list.txt' -H 'Content-Type: text/plain' \
  --data $'milk\neggs'
3Read the container
curl {{STORAGE}}notes/ -H 'Accept: application/lws+json'
